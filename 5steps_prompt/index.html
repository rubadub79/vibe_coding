찾지 말고 만들자: 교사를 위한 바이브 코딩

수업용 웹앱 제작 6단계 가이드

각 단계를 선택하여 복사 프롬프트와 작업 절차를 확인합니다.

용도에 맞는 탭을 선택한 뒤 프롬프트를 복사하여 AI에 입력합니다.

용도: 수업 준비 및 교재 원문·시각 자료 보관 
첨부한 교과서/지도서 이미지(또는 PDF)의 모든 텍스트를 위계에 맞춰 누락 없이 추출해 줘. 
대단원, 중단원, 소단원 제목은 마크다운 헤더(#, ##, ###)로 정렬하고, 2단 레이아웃은 좌측 단에서 우측 단 순서로 읽어줘. 본문과 날개단 보충 설명, 사진/삽화의 캡션을 분리해 마크다운으로 정리해 줘.

교재 속 시각 자료는 아래 규칙에 따라 말머리를 달고 정리해 줘:
1. [도표]: 마크다운 표(Table)로 전환
2. [그래프]: X축, Y축 변인과 수학적 비례 관계식 정리
3. [사진] 또는 [실험 장치도]: 배치의 형태와 핵심 관측 포인트를 텍스트로 상세히 묘사
(※ 단순 장식용 캐릭터나 삽화는 생략하고, 개념 이해에 직결된 핵심 모식도만 [개념 모식도]로 묘사해 줘.)

* 도표, 그래프, 사진/실험 장치도는 의도를 기록하며 필요시 변환합니다.

용도: 출력용 종이 활동지 및 형성평가 제작 
추출된 교재 내용을 바탕으로 학생 배포용 종이 활동지 양식으로 재구성해 줘.
1. 핵심 개념 정의는 (       ) 괄호 넣기 형식으로 처리
2. 탐구 활동의 '과정 - 관찰 결과 표 - 결론 도출' 빈칸 양식 제작
3. 하단 형성평가 문항과 예시 답안 분리

* 도표, 그래프, 사진/실험 장치도는 의도를 기록하며 필요시 변환합니다.

용도: 수업용 웹앱 기획을 위한 핵심 개념·활동 요약 
이 교재 내용을 바탕으로 학생용 수업 웹앱을 기획하려고 해. 웹앱 제작에 필요한 핵심 개념과 데이터를 요약해 줘.
1. 단원의 핵심 학습 용어와 주요 개념 정의
2. 탐구·학습 활동의 단계별 절차와 핵심 판단(분기) 기준
3. 교재 속 [도표]의 수치 데이터 및 [그래프]의 인과·비례 관계 정리

* 도표, 그래프, 사진/실험 장치도는 의도를 기록하며 필요시 변환합니다.

단원명과 목표 성격을 지정하면 맞춤형 질문 프롬프트가 구성됩니다.

브레인스토밍 프롬프트: 

        

      

    


    
    

      

      

        

          선택한 아이디어를 기반으로 브라우저에서 바로 열 수 있는 단일 HTML 프로토타입을 생성합니다.
        


        
        

          
          
        


        

          

            프로토타입 생성 프롬프트:
            
          

          

        

      

    


    
    

      

      

        

          

            생성된 웹앱을 직접 조작해 보며, 교사의 수업 의도(학습 목표, 대상 학생 수준, 차시 호흡)와 화면 구성이 정확히 맞아떨어지는지 확인합니다.
          

          

            수식 오류나 오개념뿐만 아니라 어색한 문구, 교사의 의도와 다른 피드백 규칙 등을 AI에게 자연어 대화로 지시하여 다듬어 나갑니다.
          

        


        

          

            수업 의도 반영 & 팩트체크 프롬프트:
            
          

          
방금 작성한 웹앱 코드의 교과 내용과 화면 텍스트를 점검하고 수정해 줘.

1. [교육자료 표현 및 톤앤매너 점검]:
   - 이 웹앱은 학교 수업을 위한 교육자료야.
   - 학생에게 노출되는 화면 문구에 허세, 과장된 밈, 불필요한 미사여구가 없는지 전수 점검하고, 교과 수업에 알맞은 명확하고 담백하며 정중한 표현으로 정돈해 줘.

2. [교사 수업 의도 및 피드백 수정]:
   - 내 수업 의도([수업 의도: 예 - 10분간 학생이 스스로 조작하며 핵심 개념을 발견하도록 유도])에 맞춰 조작 순서와 피드백 문구가 명확하게 제시되는지 확인하고 필요한 부분을 수정해 줘.

3. [공식 출처 및 세션 팩트체크]:
   - 웹앱에 적용된 공식, 수치, 분기 규칙의 공식 레퍼런스(교육과정 성취기준 또는 공신력 있는 공식 자료)를 이 대화 세션 창에 제시해 줘.
   - 비례 관계나 부등호 방향, 0으로 나누기 등의 논리적 오류가 없는지 점검해 줘.

        


        
        

          

            1. 수업 의도 & 지도서 대조
            단원 목표와 판정 기준이 교사의 의도 및 교과서 기준과 일치하는지 확인
          

          

            2. 교육자료 품격 & 표현 점검
            허세, 인터넷 밈, 과장된 미사여구를 배제하고 담백한 어휘 사용 여부 점검
          

          

            3. 기기 터치 반응
            학생 크롬북/태블릿에서 버튼 크기와 조작 반응이 원활한지 확인
          

        

      

    


    
    

      

      

        

          

            제미나이 캔버스 우측 상단의 [공유] ➔ [Google 클래스룸]을 누르면 교사가 개설한 클래스의 과제로 등록됩니다.
          

          

            

              1. [공유] 클릭
              캔버스 화면 우측 상단 공유 아이콘 선택
            

            

              2. [클래스룸] 선택
              등록할 학급 및 수업 과제 유형 선택
            

            

              3. 과제 게시 완료
              학생 기기 클래스룸 피드에 게시
            

          

        

      

    


    
    

      

      


        
        

          

            1) 3D 그래픽이나 고성능 시뮬레이터를 만든다면? ➔ Vercel 활용
          

          

            전체 화면 구동이나 고성능 렌더링이 필요한 Three.js 3D 천체 관측 등의 도구에 활용합니다.
          

          

            

              A. HTML 저장
              코드를 index.html 파일로 저장
            

            

              B. 폴더 업로드
              vercel.com 대시보드에 폴더 업로드
            

            

              C. 링크 배포
              생성된 단독 URL 또는 QR코드 공유
            

          

        


        
        

          

            2) 활동 결과를 저장하여 기록하고 싶다면? ➔ 구글 Sheets - Apps Script 연동
          

          

            학생들의 활동 결과를 저장하여 기록하고 싶은 경우에는, 교사 구글 드라이브에서 구글 시트를 먼저 만든 뒤 [확장 프로그램 ➔ Apps Script]로 진입해야 합니다. 시트 열 구조(헤더)에 맞춰 AI에게 Code.gs와 index.html을 한 세트로 작성하도록 요청합니다.
          


          

            시트 열(Header) 구성
            필요한 항목에 맞춰 1행 헤더를 설정합니다 (예: 제출일시 | 학번 | 이름 | 활동결과 | 자기평가).
          


          

            

              시트 연동형 Code.gs + index.html 세트 생성 프롬프트:
              
            

            
[단원명] 수업 웹앱을 Google Apps Script로 구동하여 교사 구글 시트에 학생 활동 결과를 자동 기록하려고 해. 아래 두 파일을 세트로 작성해 줘.

1. Code.gs (백엔드):
   - doGet() 함수로 index.html 웹페이지 렌더링
   - saveRecord(data) 함수: 내 시트 1행 헤더 [제출일시, 학번, 이름, 활동결과]에 맞춰 appendRow로 누적 저장

2. index.html (프론트엔드):
   - 상단에 [학번]과 [이름] 필수 입력창 배치
   - 활동 완료 후 [활동 결과 제출] 클릭 시 google.script.run.saveRecord() 호출
   - 단일 HTML (Tailwind CSS CDN) 모던 카드 디자인 적용

          


          

            배포 없이 실행만 하면 안 되나요?
            교사 혼자 쓰는 개인 도구라면 테스트 실행으로 충분하지만, 학생 30명이 각자의 기기(크롬북/스마트폰)에서 웹페이지를 열고 활동 결과를 보내려면 구글의 공개 웹 주소가 필요합니다.

            따라서 Apps Script 우측 상단 [배포] ➔ [새 배포] ➔ [유형: 웹 앱]에서 '액세스 권한: 모든 사용자(Anyone)'로 딱 한 번만 배포해 주시면, 발급된 URL을 구글 클래스룸 [과제 ➔ 링크 추가(🔗)]에 붙여넣어 학생들과 바로 공유할 수 있습니다.
